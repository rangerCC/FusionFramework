# 业务错误码

`code=0` 为成功。非 0 按模块分段。`message` 已是中文，可直接展示。

## 通用 (1xxx)

| code | HTTP | message | 说明 |
|---|---|---|---|
| 1000 | 400 | 参数错误 | 通用参数校验失败 |
| 1001 | 400 | 请求体格式错误 | JSON 解析失败 |
| 1002 | 429 | 请求过于频繁，请稍后再试 | 限流 |
| 1003 | 500 | 服务器开小差了 | 内部错误 |
| 1004 | 404 | 资源不存在 | |

## 认证 (2xxx)

| code | HTTP | message | 说明 |
|---|---|---|---|
| 2001 | 401 | 登录已失效，请重新登录 | access token 缺失/过期/非法 |
| 2002 | 400 | 手机号格式不正确 | |
| 2003 | 400 | 验证码错误 | |
| 2004 | 400 | 验证码已过期，请重新获取 | |
| 2005 | 429 | 验证码发送过于频繁 | 60s 冷却 / 当日上限 |
| 2006 | 400 | 验证码错误次数过多，请重新获取 | ≥5 次锁定 |
| 2007 | 401 | 刷新令牌无效或已过期 | refresh 失败 |
| 2008 | 401 | 登录状态异常，请重新登录 | refresh token 重放检测 |
