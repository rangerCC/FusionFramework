# 社交故事伴侣（SocialStoryMate）产品需求文档 V2.0

> **基于商业化改进方案的产品设计**  
> 文档版本：2.0  
> 更新日期：2026-06-12  
> 产品形态：iOS App (Objective-C) + Coze工作流 + 内置社交故事模板  
> 目标：打造可规模化、可持续盈利的家庭行为干预助手

## 1. 产品概述

### 1.1 产品定位
**社交故事伴侣**是一款面向ASD/ADHD儿童家长的家庭行为干预辅助工具。它从“故事生成器”升级为“行为记录+智能建议+故事生成+效果追踪”的完整闭环，帮助家长在自然情境中实施循证干预。

### 1.2 核心价值
- **一站式**：从问题描述到行为改善跟踪，全流程支持
- **低成本**：预置模板故事+AI增强，按需付费
- **可量化**：行为数据可视化，家长清晰看到进步
- **隐私优先**：默认本地存储，AI图片无脸设计

### 1.3 目标用户
- **主要用户**：3-12岁ASD/ADHD儿童的家长（中高付费意愿）
- **次要用户**：特教老师、行为治疗师（B端工作台）
- **间接用户**：儿童本人（阅读/收听故事）

## 2. 功能需求（按商业化改进方案重构）

### 2.1 儿童档案管理（基础）
与V1.0相同，增加以下字段：
- 昵称、出生日期、诊断标签、语言水平、特殊兴趣、强化物
- **新增**：行为基线记录（可选）—— 家长可手动记录该儿童每周目标行为的初始频率（如“超市哭闹每周3次”），用于后续对比。

### 2.2 行为记录与追踪模块（新增核心）

**2.2.1 快速行为记录**
- 家长在每次使用故事前后，可记录一次行为结果：
  - ✅ 成功（孩子达到期望行为）
  - 😐 部分成功（有进步但未完全达到）
  - ❌ 失败（无改善或恶化）
- 支持添加语音备注（15秒）
- 自动记录时间、关联的情境和故事

**2.2.2 行为趋势看板**
- 可视化图表（折线图/柱状图）展示：
  - 每周目标行为的成功率变化
  - 不同情境下的成功率对比
  - 使用故事次数 vs 行为改善的相关性
- 可导出报告（PDF/图片），用于分享给治疗师或医生

**2.2.3 行为基线设定**
- 家长可为目标行为设定初始频率（如“每周哭闹5次”）
- 系统自动计算改善幅度（例如“使用故事2周后，频率降至2次，改善60%”）

### 2.3 社交故事生成与模板系统

**2.3.1 三层故事来源（重点改进）**

| 层级 | 来源 | 特点 | 适用场景 |
|------|------|------|----------|
| **L1: 预置模板故事** | 内置100+专家编写的故事库（JSON本地） | 立即可用、零成本、无AI生成延迟 | 常见情境（如“上厕所”“分享玩具”），可离线使用 |
| **L2: AI增强故事** | 基于模板或用户输入，通过Coze工作流个性化 | 融入儿童特殊兴趣、强化物，生成时间3-8秒 | 用户对模板不满意或需要高度个性化 |
| **L3: 完全自定义故事** | 家长手动编辑（文字+图片拼贴） | 最大灵活性，可上传真实照片 | 特殊场景或偏好 |

> **商业化设计**：免费用户只能使用L1模板故事（有限数量，如20个）；订阅用户可无限使用L2和L3。

**2.3.2 故事生成向导（简化版，融入模板优先）**
- Step1：选择情境（从模板分类库中选择，或自由输入）
- Step2：若选择模板，直接展示预置故事内容（可编辑修改）
- Step3：若选择“AI增强”，则进入个性化参数（特殊兴趣、强化物等），调用Coze工作流
- Step4：生成后支持手动编辑、插入本地图片（从相册选择，无脸角色或真实照片均可）

**2.3.3 图片生成策略（成本优化）**
- **默认模式**：使用本地素材库进行**拼贴式插图**（200+无脸角色、背景素材），自动匹配句子语义，生成固定组合图。此模式免费且即时。
- **高级模式**：调用AI绘图（用户主动触发），生成完全自定义图片。每次消耗0.5个故事点数。
- **家长插入模式**：家长可上传自己拍摄的真实照片（需确认隐私提示），App仅做排版。

### 2.4 故事管理与使用计划（新增“泛化提醒”）

**2.4.1 故事库**
- 按儿童筛选、按情境分类、按最近使用排序
- 每个故事展示：标题、最后使用时间、成功率（根据行为记录自动计算）

**2.4.2 泛化阶梯提醒（自动化干预计划）**
- 用户可为故事设置**使用计划**：
  - 第1-3天：每晚睡前讲一次
  - 第4-7天：在情境发生前（如去超市前）讲一次
  - 第8-14天：情境中若出现困难，立即使用
  - 第15天后：撤除故事，仅口头提示
- App根据计划推送通知：“今天是第5天，请在去超市前给乐乐讲‘超市购物’故事”
- 用户完成计划后，标记“泛化成功”，系统记录并鼓励。

**2.4.3 效果反馈聚合**
- 所有行为记录自动关联到故事
- 用户可查看“这个故事在过去2周的成功率：75%”

### 2.5 B端治疗师工作台（Web后台，后期实现）

**目标用户**：康复机构、特教老师、行为治疗师  
**核心功能**：
- 登录后管理多个儿童档案（批量导入/导出）
- 为每个儿童快速生成故事（调用Coze工作流，支持批量生成）
- 查看儿童的行为数据报告（按机构汇总）
- 创建机构专属故事模板库（共享给内部家长）
- 定价：年费1200元/账号，含500个故事点数

**技术实现**：独立Web应用（React/Vue），后端API与Coze对接，数据独立于iOS App（但可通过邀请码关联家长端）。

### 2.6 数据隐私与合规增强

- **本地优先**：所有儿童档案、行为记录、故事内容默认存储在Core Data，仅当用户主动使用AI生成时才传输必要字段到Coze。
- **隐私政策**：启动页强制阅读并同意（家长确认）。
- **真实照片使用警告**：当家长上传孩子真实照片时，弹出提示：“此照片仅存储于本机，不会上传。请勿分享包含其他儿童的照片。”
- **数据导出/删除**：用户可一键导出所有数据（JSON），或彻底删除账号及所有本地数据。

## 3. 非功能需求

| 需求 | 说明 |
|------|------|
| **启动速度** | 冷启动<2秒，首页加载预置模板故事<0.5秒 |
| **离线可用** | L1模板故事、行为记录、本地拼图完全离线；AI增强故事需联网但可降级提示 |
| **AI响应时间** | 故事生成<5秒（不含AI绘图）；AI绘图若启用，单独加载<15秒 |
| **存储空间** | 预置模板+素材库约50MB；用户数据随使用增长 |
| **隐私** | 所有用户生成内容不上传（除主动调用AI时传输的必要字段） |
| **国际化** | 首版简体中文，预留多语言接口 |

## 4. 技术架构（iOS + Coze工作流 + Web后台）

### 4.1 iOS App (Objective-C)

**核心框架**：
- UI：UIKit + Auto Layout，支持动态字体
- 数据存储：Core Data + CloudKit（可选同步）
- 网络：NSURLSession（调用Coze API）
- 图片处理：UIKit + 本地素材拼贴引擎（Core Graphics）

**模块划分**：
- `MHChildManager`：儿童档案CRUD
- `MHBehaviorRecord`：行为记录与统计
- `MHStoryEngine`：故事生成（模板库、AI调用、手动编辑）
- `MHImageComposer`：本地图片拼贴（素材库管理）
- `MHNotificationScheduler`：泛化提醒推送

**Coze API调用封装**：
```objc
// 请求参数
NSDictionary *params = @{
    @"child_name": child.name,
    @"situation": situation,
    @"special_interests": child.interests,
    ...
};
// 异步调用，支持超时重试
[CozeClient generateSocialStory:params completion:^(NSDictionary *result, NSError *error) {
    // 处理故事文本、图片提示词等
}];
```

## 4.2 Coze工作流设计（已优化）

**工作流名称**：`SocialStory_Enhanced_V2`  
**输入参数**：同 V1.0，增加 `story_level` (template/augmented)  
**流程**：
1. 若 `story_level == template`：直接返回预置模板内容（不走LLM，快速）
2. 若 `story_level == augmented`：
   - LLM生成个性化故事（沿用之前提示词，但限制句长）
   - 仅生成文本，不生成图片提示词（图片由App本地拼贴）
   - 返回JSON

**成本控制**：AI增强版本仅使用LLM，不调用绘图API，单次成本约0.01元。

## 6. 操作流程示例（用户旅程）

**场景**：4岁ASD儿童“乐乐”在超市经常躺地哭闹。妈妈第一次使用App。

1. **下载App** → 注册（仅需邮箱，可选） → 创建儿童档案“乐乐”。
2. **首页** → 点击“记录行为基线” → 输入“超市躺地哭闹，每周约4次”。
3. **生成故事** → 搜索“超市” → 展示预置模板故事“去超市购物”。
4. 妈妈预览故事文本和本地拼贴图，觉得不错 → 保存到故事库。
5. **设置使用计划** → 选择“泛化阶梯” → 设置提醒时间（今晚讲、明天去超市前讲）。
6. 当晚收到推送 → 打开App点击“讲故事” → 展示图文+自动语音朗读。
7. 讲完后 → 记录行为结果“成功”（孩子安静听完）。
8. 第二天去超市前再次使用 → 回来后记录“部分成功”（在超市提醒后停止哭闹）。
9. 一周后 → 行为看板显示“超市哭闹从每周4次降至1次，改善75%”。
10. 妈妈决定订阅专业版（29.9元/月） → 解锁无限AI增强故事，并为乐乐的“理发”情境生成个性化故事。

## 8. 验收标准（关键场景）

1. **离线可用性**：关闭网络，用户仍可浏览L1模板故事、创建行为记录、查看已保存故事。
2. **AI生成速度**：Wi-Fi环境下，从点击“AI增强”到展示故事文本<5秒。
3. **行为数据准确性**：用户记录3次“成功”后，看板显示成功率100%，且支持按周筛选。
4. **订阅购买**：使用沙盒测试，能完成购买并解锁专业版功能。
5. **隐私合规**：上传真实照片时，必现隐私提示，用户确认前无法插入。

## 9. 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 用户不习惯行为记录 | 提供简化的3级按钮，通过奖励提示（如“记录满7天解锁新头像”）培养习惯 |
| 模板故事不够用 | 上线后每月根据用户反馈增加10-20个新模板（低成本维护） |
| Coze API不稳定 | 实现超时重试（3次），降级时提示用户稍后重试，并使用本地缓存版本 |
| 治疗师后台没人用 | 先免费邀请10家机构试用，收集反馈后定价，主打“提高工作效率”价值 |

## 10. 附录：预置模板故事示例

**情境**：超市购物  
**文本**：
> 我和妈妈去超市。超市有很多东西。有时候我想要玩具，但是妈妈说“今天不买”。我可以摸一下玩具，然后放回去。妈妈会奖励我一颗星星。我做到了！

**拼贴图**：超市货架背景 + 无脸儿童角色 + 星星贴纸素材。

**使用频率建议**：每次去超市前讲，连续3次后尝试只口头提醒。
